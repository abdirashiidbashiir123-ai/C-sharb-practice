# C# Practice Repository

This repository is organized to support a structured C# learning journey across multiple weeks.

## General Subjects Covered
- C# fundamentals and syntax
- Variables, constants, and data types
- Operators and expressions
- Conditional statements and loops
- Methods and code reuse
- Classes, objects, and OOP basics
- Arrays, collections, and string operations
- Exception handling
- Console application development
- Problem solving with C#

## Purpose
Each week contains chapter notes and a screenshot folder for saving examples, outputs, and visual progress.

## Learning Approach
- Read and understand the weekly chapter notes
- Practice coding examples in C#
- Save screenshots for progress tracking
- Review and improve concepts week by week
