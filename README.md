Chapter 1 – Introduction to Visual C#


Objects: Program components that contain data and perform operations.

Properties: Data or settings stored in an object.

Methods: Operations that an object can perform.

Controls: Visible GUI objects such as Buttons, Labels, and TextBoxes.

Classes: Code that describes a particular type of object.

.NET Framework: A collection of classes and code used to create Windows applications.

Visual Studio: An Integrated Development Environment (IDE) used to develop applications.

Toolbox: Used to select and add controls to a form.

Properties Window: Used to change the appearance and behavior of objects.

Projects and Solutions: A solution can contain projects, while a project contains the files needed for an application.

Windows Forms: Used to create the graphical user interface of an application.

C# Code: Organized mainly into namespaces, classes, and methods.

Event-driven programming: The application responds to events such as button clicks and keyboard actions.

MessageBox: Used to display messages.

Labels and PictureBox: Used to display text and images.

Comments and indentation: Make code easier to understand.

Syntax errors: Errors in code that Visual Studio identifies while writing or compiling.  


Chapter 2 – Processing Data



TextBox input: Used to receive keyboard input from the user.

Variables: Memory locations used to store data.

Data types: Define the kind of data a variable can store.

String: Stores combinations of characters.

String concatenation: Combines strings using the + operator.

Variable scope: Defines where a variable can be accessed.

Numeric data types: Includes int, double, and decimal.

Type casting: Converts a value from one data type to another.

var keyword: Allows C# to determine a local variable's type automatically.

Arithmetic operators: +, -, *, /, and %.

Integer division: Division between integers produces an integer result.

Parsing: Converts string input into numeric data using methods such as int.Parse() and double.Parse().

ToString() method: Converts values into strings for display.

Number formatting: Formats numbers as numbers, currency, percentages, etc.

Exception handling: Uses try-catch to handle runtime errors.

Named constants: Uses const for values that should not change.

Fields: Variables declared at class level.

Math class: Provides mathematical methods such as Math.Sqrt(), Math.Pow(), Math.Max(), and Math.Min().

GUI details: Includes focus, tab order, access keys, colors, background images, GroupBoxes, and Panels.

Debugging: Uses breakpoints, Locals, Watch windows, and single-stepping to find logic errors.
